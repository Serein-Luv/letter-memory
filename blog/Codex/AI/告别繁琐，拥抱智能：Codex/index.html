告别繁琐，拥抱智能：Codex

发表于 2026-06-30 分类于 Codex ， AI 本文字数： 865 阅读时长 ≈ 3 分钟

AI 编程工具的风向真是说变就变，从之前的 Cursor 到 Claude Code，而现在，聚光灯打在了 OpenAI 官方出品的 Codex 身上。它可不只是个简单的“代码补全”工具，而是一个能直接操作你电脑上的文件、浏览器、甚至是桌面应用的智能代理人（Agent）。

一 安装前的准备

  1. 一个 ChatGPT 账号：Codex 桌面 App 需要使用 ChatGPT 账号登录。

  2. 安装好 Git 和 Node.js (LTS 版本)

    Git可选，但是Node.js是必须的，使用CLI命令行工具。

  3. 安装 Codex 桌面 APP。

    下载链接：https://openai.com/zh-Hans-CN/codex/

  4. 登录账号

    首次启动 Codex，使用你的 ChatGPT 账号登录。网上许多GPT账号都需要国外电话验证，流程相当繁琐。这边建议选择其他方式登录，选择API密钥登录。

二 Agnes模型

给Codex装上免费的全能大脑。

Codex 的能力很强，但官方模型有额度限制，想放开手脚用？把 Agnes 模型 接进 Codex，可能是目前性价比最高的选择——文本模型 Agnes-2.5-Flash 免费、不限期，还能顺带解锁生图、生视频能力。

为什么是 Agnes？

Agnes 是专为 Coding 和 Agent 场景 优化的大模型家族，对代码理解、多文件修改、多步骤任务执行都有专项提升。其最新发布的 Agnes-2.5-Flash，在 SWE-bench Verified 上达到了 75.6%，相比上一代提升了 3 个百分点以上。

最关键的是：不限期免费开放，非常适合 Codex 新手和日常高频使用。

而且 Agnes 不只是文本模型，还提供：

模型 能力 付费情况
Agnes-2.5-Flash 文本对话、代码生成、Agent 任务 免费
Agnes-Image-2.1-Flash 文生图、图生图 免费（有额度）
Agnes-Video-V2.0 文生视频 免费（有额度）

使用方式

  1. 下载 CC-Switch 配置工具
  2. 注册 Agnes 平台账号：https://platform.agnes-ai.com/login

  • 获取 API Key：

    登录后进入「设置 → API 密钥」，点击「创建新密钥」，复制生成的 sk-xxx 字符串。

  • 下载 CC-Switch 图形化配置

    1. 启动 CC-Switch，点击顶部「OpenAI」图标，右上角「新增供应商」

    2. 预设供应商选择「自定义配置」

    3. 粘贴 Agnes API Key

    4. 填写 API Base URL：https://apihub.agnes-ai.com/v1

    5. 在「模型映射」中添加模型：agnes-2.5-flash

    6. 关键步骤：打开「本地路由映射」开关，并开启「路由总开关」和「Codex 路由」

    7. 保存配置，切换到新创建的渠道，完全退出并重启 Codex

      最后验证： 在 Codex 中发送一个简单指令，如果正常返回，说明配置成功。
