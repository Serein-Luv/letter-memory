Windows查看CPU和GPU配置

发表于 2023-09-03 分类于 互联网 本文字数： 361 阅读时长 ≈ 1 分钟

在Windows系统中，可以通过任务管理器、系统信息、DirectX诊断工具以及第三方软件快速查看CPU和GPU信息。

  • CPU 配置查询

    • 此电脑查询

      桌面-此电脑（右键）-属性可以查看CPU处理器规格

  • 系统信息工具（msinfo32）

    • 按 Win + R，输入 msinfo32 并回车：
    • 在“系统摘要”中查看CPU型号、内存大小、系统类型等。

  • DirectX诊断工具（dxdiag）

    按 Win + R，输入 dxdiag 并回车：

    • 在“系统”选项卡查看CPU型号。
    • 在“显示”选项卡查看显卡名称、制造商、芯片类型和专用显存大小

  • GPU查询

    • 在【任务管理器】中查看显卡信息

      使用【任务管理器】是在Windows 10/11 查看显卡信息最快捷的方法之一。

      按Ctrl+Shift+Esc快捷键，或右键点击任务栏空白处，选择打开【任务管理器】。

      打开【性能】选项卡，找到并点击GPU项目。在页面顶部，就会看到GPU名称。

  • 通过【DirectX诊断工具】查看显卡信息

    • Windows+R 打开运行对话框，输入dxdiag并回车。
    • 在界面顶部点击【显示】选项卡。

  • 通过【系统信息】应用查看GPU信息

    • 使用Windows+R 打开运行对话框，输入 msinfo32 并按回车。
    • 在打开的窗口中，点击展开【组件】下的【显示】选项。在界面的右侧，可以看到关于GPU的详细信息。
