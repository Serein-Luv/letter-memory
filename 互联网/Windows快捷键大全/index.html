Windows快捷键和运行命令大全

发表于 2022-12-21 分类于 互联网 本文字数： 892 阅读时长 ≈ 3 分钟

掌握 Windows 快捷键可以显著提高操作效率，包括系统操作、窗口管理、文件管理和文本编辑等多方面功能。

系统与桌面操作

  • Win：打开或关闭开始菜单
  • Win + D：显示或隐藏桌面
  • Win + L：锁定电脑
  • Win + E：打开文件资源管理器
  • Win + I：打开设置
  • Win + Tab：打开任务视图，切换虚拟桌面
  • Win + . / ;：打开表情符号面板
  • Alt + Tab：在打开的应用之间切换
  • Ctrl + Alt + Del：打开安全选项（锁定、注销、任务管理器）

文件与资源管理

  • Ctrl + C / Ctrl + X / Ctrl + V：复制、剪切、粘贴
  • Ctrl + Z / Ctrl + Y：撤销/恢复操作
  • F2：重命名选定文件或文件夹
  • Delete / Shift + Delete：删除选定项或永久删除
  • Ctrl + A：选择所有项目
  • Ctrl + F：在文件资源管理器中搜索文件或文件夹
  • F5：刷新活动窗口

文本编辑快捷键

  • Ctrl + A：全选文本
  • Ctrl + B / I / U：加粗 / 斜体 / 下划线
  • Ctrl + C / X / V：复制、剪切、粘贴
  • Ctrl + Z / Y：撤销/重做
  • Ctrl + 左/右箭头：移动光标到上一个/下一个单词开头
  • Ctrl + 上/下箭头：移动光标到上一段/下一段开头
  • Ctrl + F / H：查找 / 查找并替换

窗口与多任务管理

  • Win + ↑ / ↓ / ← / →：最大化、最小化或将窗口贴靠到屏幕边缘
  • Win + Shift + ↑ / ↓ / ← / →：在多显示器间移动窗口或调整窗口大小
  • Alt + F4：关闭当前窗口或应用
  • Ctrl + Shift + Esc：直接打开任务管理器

功能键与特殊操作

  • PrintScreen / Alt + PrintScreen：截取全屏或当前窗口
  • Scroll Lock / Pause / Break：控制滚动条或暂停操作
  • Insert：切换插入/改写模式
  • Caps Lock / Num Lock：切换大写锁定或数字键盘状态
    掌握这些快捷键可以大幅减少鼠标操作，提高工作效率。建议每天学习几个常用快捷键，逐步形成熟练操作习惯，从而在 Windows 系统中实现快速、高效的操作

Windows 运行命令大全

在 Windows 系统中，通过 运行窗口（快捷键 Win+R）可以快速打开各种工具和功能，大幅提升操作效率。以下是一些常用的运行命令及其功能：

系统信息与配置

  • winver：查看 Windows 版本信息。
  • msconfig：打开系统配置实用程序。
  • msinfo32：查看系统信息。
  • sysdm.cpl：打开系统属性。

管理工具

  • compmgmt.msc：计算机管理。
  • devmgmt.msc：设备管理器。
  • diskmgmt.msc：磁盘管理。
  • eventvwr：事件查看器。
  • services.msc：本地服务设置。
  • taskmgr：任务管理器。

安全与用户

  • netplwiz：高级用户账户设置。
  • secpol.msc：本地安全策略。
  • certmgr.msc：证书管理器。
  • firewall.cpl：Windows 防火墙设置。

显示与输入

  • desk.cpl：屏幕分辨率设置。
  • main.cpl：鼠标属性。
  • osk：屏幕键盘。
  • magnify：放大镜工具。

文件与工具

  • explorer：打开文件资源管理器。
  • notepad：启动记事本。
  • mspaint：打开画图工具。
  • calc：启动计算器。
  • snippingtool：截图工具。

网络与连接

  • ncpa.cpl：网络连接设置。
  • mstsc：远程桌面连接。
  • iscsicpl：iSCSI 管理器。

诊断与测试

  • dxdiag：DirectX 诊断工具。
  • mdsched：Windows 内存诊断。
  • perfmon：性能监视器。

命令与脚本

  • cmd：打开命令提示符。
  • powershell：启动 Windows PowerShell。
  • mmc：打开控制台。

其他常用命令

  • control：打开控制面板。
  • appwiz.cpl：卸载或更改程序。
  • powercfg.cpl：电源选项设置。
  • wusa：Windows 更新独立安装程序。

通过这些命令，用户可以快速访问系统功能，简化操作流程，提高工作效率。
